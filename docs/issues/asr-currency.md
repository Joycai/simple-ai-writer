# 转写费用的货币：¥ 记进了 `cost_usd` 列

> **状态：`open` · 待办，不急**（作者 2026-09-06：「记一个待办，以后再说」）。只失真用量页的合计，不影响转写本身。

## 是什么

`token_usage.cost_usd` 是全库唯一的成本列，以美元计；而 DashScope 的录音文件识别按**人民币**计（¥0.00022 / 秒），设计稿 02f 决定界面上全用 ¥（模型抽屉的「每秒单价 ¥ / 秒」、确认卡的估价、完成通知的「¥0.01」）。于是 `lib/asr/run.ts` 的 `recordTranscriptionUsage` 写进 `cost_usd` 的其实是一个 ¥ 数——设置 → 用量 把它和文本模型的美元加在一起，合计是两种货币的和。

## 两条出路（哪条都行，等有人在意时再选）

1. **用量表记货币**：`token_usage` 加一列 `currency`（缺席 = USD），用量页按货币分组合计。改动在 `lib/ai/usage.ts` 的 rollup + Settings → 用量 的表头；最忠实，但要动一张已有数据的表。
2. **设置里定一个汇率**：装机级偏好 `app:cnyPerUsd`，转写入账时除一下，用量页仍然只有一列美元。改动最小，但汇率会过期，而且抽屉上作者填的是 ¥、用量页看到的是 $。
