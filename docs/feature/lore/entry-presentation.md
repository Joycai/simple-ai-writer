# 知识库条目展示导出

> 状态：`living`

## 入口与范围

知识库墙的单条右键菜单、详情页（阅读 / 管理共用）的「更多」菜单提供
「导出展示页 · HTML」「打印展示页 · PDF」「导出展示页 · Markdown」。
原来的 ZIP 导入导出继续负责可恢复备份；展示页负责交给读者阅读。
编辑尚未保存时不提供详情菜单，导出取磁盘上的已保存内容。

读取 index.md 的全部元数据与正文、所有特征（包括 manual 和不命中的 auto）、
普通 Markdown 附件、头像、封面、图集描述和槽位，以及未登记进图集的图片。
子目录内的 Markdown 和图片也读取，正文图片按所在文件目录解析。
images.md 图片块之前的作者文字保留为图集引言，每张图片的描述完整展示。
读取直接来自文件系统，而不依赖上下文预算或扫描器的图片清单：扫描器会忽略缺失图片，
导出若沿用该清单便会把内容缺失伪装成成功。任何文件读取或本地图片嵌入失败均停止。

## 呈现与移植性

HTML 是单文件页面，含完整 CSS 和本地图片 data URL；Markdown 从同一内容转换，
带目录锚点、元数据列表、GFM 表格和内嵌图片，公式恢复为 TeX。
引用保留目标标识，但不会递归导出被引用的其他条目。
HTTP(S) 图片保留远程链接，需要联网；不在后台代作者下载外链资源。
Markdown 阅读器需要允许 data URL 图片；不支持时优先使用 HTML / PDF。
二进制非图片附件不是可展示正文，也不作为附件打包；完整备份仍用 ZIP。

展示页使用固定浅色纸张、衬线正文、无衬线元数据、单色强调、响应式留白和目录。
它有自己的原始 CSS 文件，不继承应用当前深色主题或小说正文首行缩进：
独立档案含大量元数据、图片与短段落，布局需要稳定，并适合纸面打印。
公式用 KaTeX 生成的 MathML，避免独立文件依赖应用内的字体 URL。
打印采用 A4 页边距、图片限高、标题与后文连排；每个特征可跨页，避免长特征被整块挤走。
PDF 复用现有原生打印路径，在系统打印对话框里保存为 PDF，不添加新的 PDF 引擎。

导出不调用模型，不修改源文件。原生保存对话框取消即结束；读取、图片或保存失败显示错误。
同一入口运行中阻止重复发起；模块按需加载，避免给主界面增加转换依赖。

## 验证

`src/lib/lore/__tests__/presentation.test.ts` 验证各注入模式内容完整性、正文与引用式图片、
图片去重、缺图 / 读失败中止、元数据转义、公式和代码保真、输出格式分发与取消保存。
