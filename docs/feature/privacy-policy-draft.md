## 本地数据

文档、知识库、项目数据库、对话与任务记录、用量、素材和缓存保存在项目目录或应用数据目录。API 凭据保存在系统凭据管理器。文件访问依靠用户选择目录与本机书签恢复；书签和数据分享同意不进入配置备份。诊断日志为可选功能，可能记录请求与回复，分享前应检查敏感内容。

## 在线处理与接收方

本地编辑不要求使用在线服务。启用 AI 写作、翻译、多模态、检索或音频转写后，根据所选功能，指令、正文或选区、自动上下文、知识库材料、历史、摘要、工具结果、附件、图片、音视频及服务凭据可能发送到配置的服务。媒体上传存储与结果下载可能使用不同地址，会分别检查许可。

MCP 将客户端信息、发现请求和工具参数发送到配置的服务器。参数可能包含项目文本和文件路径，服务器可以执行操作或继续转发，工具操作审批不替代隐私许可。

知识库同步发送条目、图片、结构、路径与版本信息。配置备份发送供应商 / 模型 / 提示词、可迁移偏好及备份概要；仅在用户另行选择时携带 API 密钥，含密钥载荷必须密码加密，认证信息和信封概要仍可被服务器看到。

模型检测发送认证信息、模型标识与测试文本，可能计费。字体下载请求固定包、版本和资源文件，不包含正文或 AI API 密钥；下载站点可接收 IP 等正常连接信息。

本机和局域网地址、中转服务也可能向其他服务转发。各运营方的数据保留、训练用途、转发与删除规则由其条款决定；用户应在授权前了解对应服务。应用不把“本地地址”描述为绝不外传。

## 同意、撤回与删除

发送前告知实际地址、用途、数据范围并取得明确许可。同意只在本机保存，按接收方 / 用途 / 告知版本管理，不随配置迁移。拒绝后仍可本地编辑。文件访问、工具审批和费用确认分别管理。

设置 → 关于 → 隐私与数据分享可撤回并暂停后续请求，应用尽力取消活动请求，但不能召回已发出的内容，也不能保证服务端任务立即停止。允许再次询问不会直接授予权限。

删除项目、缓存与备份需分别处理；移除最近项目记录不删除文件。重置应用配置删除应用配置及本应用的凭据，不删除项目文件或外部备份。远端数据应向对应服务运营方申请删除，本应用不能替第三方保证执行结果。

本项目的上述功能未接入广告或跟踪 SDK。最终商店隐私申报须按 Apple 定义及真实数据处理行为评估，不能据此自动申报所有类别“不收集”。

完整技术数据流与尚未验收项见 [Mac App Store 计划 §9](mac-app-store-plan.md#9-p2-实施记录2026-11-04)。
