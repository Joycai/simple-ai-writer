商店候选范围为 Apple Silicon、macOS 14 及以上；须分别记录最低系统和拟支持系统的实机结果后才能正式承诺。Intel 暂不进入商店首发，站外版不变。每次记录版本、二进制 SHA-256、系统版本、芯片、签名身份、步骤、预期、实际和证据。当前在 arm64 / macOS 27.0.1 主机完成构建、静态审计及部分 P1 原生交互，尚未完成该主机完整矩阵或 macOS 14 实机验收。

## 准备

```bash
pnpm tauri:appstore
pnpm audit:appstore --output /tmp/store-audit.json
node scripts/create-appstore-fixtures.mjs
node scripts/appstore-test-server.mjs --host 127.0.0.1 --port 17842 --mode normal
```

使用 `src-tauri/target/app-store/aarch64-apple-darwin/release/bundle/macos/Simple AI Writer Store.app`；旧的不带目标架构目录不是当前产物。审计核对身份、版本、arm64、Mach-O / plist 最低系统、签名完整性、六项沙盒权限、动态库和资源。报告始终保留 `submissionReady: false`，不会把 ad-hoc 当作正式签名。

样例生成器在系统临时目录创建空项目与独立导入源，覆盖中文 / 空格、Markdown、文本、HTML、PNG、DOCX、XLSX、PPTX、PDF、WAV，并打印 manifest 路径。生成不等于导入成功。导入后执行 `node scripts/create-appstore-fixtures.mjs --verify <manifest.json>` 确认源文件未变；测试结束可删除本次打印的临时根目录。

本地服务只绑定回环，启动时打印 API URL。配置为 OpenAI 兼容服务、模型 `p3-local-model`，如 UI 要求密钥只填合成字符串。`GET /__status` 只记录路径、方法、字节数、关闭时间状态，不记录正文或认证头；`POST /__reset` 清空计数。服务没有 MCP / 音频 / 图片协议，不能用它声称这些路径已通过。Ctrl-C 停止服务。

## 验收矩阵

以下为完整验收范围；逐项进度见本轮执行记录，未记通过的子步骤继续 **待原生验收**。失败须记录复现步骤并修复，不能删除项目来跳过失败。

| 范围 | 操作与通过标准 |
| --- | --- |
| 安装 / 并存 / 升级 | 两渠道同时安装，分别配置模型和偏好，验证数据与钥匙串隔离；正式同身份签名升级后保留配置和授权；跨渠道打开同一项目正确提示锁 |
| P1 授权与重启 | 原生选择样例项目、编辑保存、完全退出再开、重启系统再开；最近 / 固定项目恢复访问；旧路径无书签时要求重新选择，取消不读取项目 |
| P1 授权失效 | 移动 / 删除项目、损坏书签、外置盘断开重连、iCloud 未下载文件、两进程同时授权；可读错误与重新授权，不能扩大根范围或丢失其他授权 |
| 编辑与数据库 | 新建 / 重命名 / 移动 / 删除文件，搜索、知识库读写、用量和任务持久化；退出恢复内容；只读目录和保存失败不报告成功 |
| 导入 / 常规导出 | 逐一导入合成样例，图片可见、中文路径正确；导出选择取消无写入，授权后正常保存；manifest 校验源文件字节不变 |
| Office / 预览 / 打印 | 打开相应 Beta，导出 DOCX / XLSX / PPTX 并用实际阅读器检查；本地图片 / 字体显示，打印及保存 PDF；远程资源 HTML 不得绕过 P2 门禁 |
| 字体 / 通知 / 钥匙串 | 字体下载许可、拒绝、删除和离线回退；通知拒绝 / 允许；凭据保存、重启读取、删除及正式签名升级 |
| P2 首次 / 拒绝 | 本地服务计数清零，首次发送显示用途 / 接收方；拒绝后请求数为零，自动重试不重复询问；重启拒绝仍有效，本地编辑可用 |
| P2 撤回 / 中断 | `--mode slow`：流式输出中撤回并暂停，连接关闭；另一进程撤回也能终止；下一次及重启后不发送；允许再次询问本身不发请求 |
| IPv6 / 网络异常 | 使用 `--host ::1` 和打印的 IPv6 URL；`--mode disconnect` 断流无假成功、可恢复；`--mode redirect` 返回 307，商店不得请求 `/redirect-target`；停止服务验证离线错误 |
| MCP / ASR / 编排 / 状态记忆 | 分别使用合成输入及受控测试服务，验证发现 / 调用 / 上传 / 轮询和恢复前许可，费用及写入审批仍成立；暂停后后台重试不发送；无受控服务则继续待验收 |
| 禁用功能与恢复 | 导入含三个关闭开关、Sakura / Comfy 模型和旧角色会话的配置；开关不可开启，旧任务 / 绑定不执行或联网，数据保留；旧终端任务继续降级 tools |
| 容量与异常退出 | 在可丢弃的小容量测试卷模拟满盘 / 不可写，保存与导出报告失败；强退后 DB / 任务恢复可用，不重放未批准动作；不可用真实磁盘灌满方式测试 |
| 站外回归 | 同样旧配置下角色扮演、Sakura、Comfy 和终端原有开关有效；文件、网络和系统候选限制不施加到站外版 |

回环 IPv6 通过只能证明回环路径，不能替代 IPv6-only / DNS64 网络验收。上传取消无法撤回已送达远端的数据，也不保证远端任务停止。
