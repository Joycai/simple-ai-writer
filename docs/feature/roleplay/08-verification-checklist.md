## 1. 第一优先：记忆区那条链

这是最近三个 PR 的落脚点，而且**一次都没在真实模型下跑过**。三步是一条链，前一步
不对后一步没有意义。

### ① 转场 · 接续能写出前情

编辑抽屉 → 转场 → 接续 → 生成前情。

- **看什么**：跑出来的那段是不是**第一人称**、是不是**只写角色知道的事**。
  如果它写成「沈砚和阿箬谈了……」那是旁观者视角，说明 system prompt 没接对。
- **确认之后**：记事本的「常驻」层里应该多出一条**前情**；稿面顶端应该出现
  「第 N 场 · 接续自第 N-1 场」那条带，前情挂在下面。
- **错了会怎样**：接续等于另起一场，角色失去上一场。

### ② 降级 · 转场之后旧记录沉进记忆区

前提：这个角色**绑了记忆区**（编辑抽屉里的「记忆区」一节，选「新建一个」）。

先聊几轮，让角色记下几条东西（事件、笔记），然后转场。

- **看什么**：记事本下半部分的「记忆区」层里，那几条应该**各成一条**出现，
  **各自带着关键字**。不是合成一段话。
- **同时**：常驻层里应该只剩没兑现的约定/待办、关系，和最新那条前情。
- **错了会怎样**：记忆区永远是空的，第 ③ 步无从谈起。

### ③ 命中 · 隔一场之后旧事被想起来

②之后，在新的一场里提一个旧条目的**关键字**（比如「塔」）。

- **看什么**：角色回复的**上方**应该出现一行「← 想起了 <条目名>」。
  然后**角色真的提到了那件事**。
- **错了会怎样**：这是整套东西的落脚点。①②对而③不对，说明关键字这条路没通——
  **比其他任何一条都值得先知道**。
- **③ 不对时先查**：那条记忆的关键字里到底有没有你说的那个词（记事本 →
  浏览全部 → 点开那条看「关键字」）。关键字是模型自己起的，它可能起了别的词。

### ④ 继承

删掉一个绑了记忆区的角色，新建一个角色，在「记忆区」一节选「绑定已存在的」，
挑刚才那个。

- **看什么**：新角色应该能想起里面的旧事（照 ③ 的方法试）。
- **错了会怎样**：「删掉角色不会删掉记忆」这句承诺不成立。

## 2. 第二优先：转场的另外两支

- **另起一场**：不该产生前情。稿面顶端那条带只剩上半截（「第 N 场 · 已封存 N-1 场」），
  下面**没有**前情挂着。
- **「不要前情」**：在预览界面点它，应该**按另起一场落地**，而不是取消转场。
- **「同时清空记忆」**（只在另起一场出现）：清掉常驻的约定/待办/关系和最新前情，
  **记忆区里的条目不动**。

## 3. 第三优先：这几个月攒下的界面，都没在真机上试过

按「撞到会烦」排，不按重要性：

| 验什么 | 怎么试 | 期望 |
|---|---|---|
| **关掉面板不中断** | 生成中途关掉 AI 抽屉，再打开 | 仍显示「生成中」，回复照样落下来 |
| **按停之后重试** | 生成中按「停止」 | 稿面上出现一行「已停止，这一问还没有回复 · 重试」，点了能接着跑 |
| **跑失败重试** | 断网发一句 | 错误带右侧出现「重试」 |
| **图片附件** | 输入框 `+ 图片` 或 `@` 挑一张图 | 多模态模型下角色真的看到了图；纯文本模型下**不该**出现这个按钮 |
| **引用选中正文** | 在编辑器里选一段，回扮演 | 附件行出现「选区 N 字」，发完自动摘掉 |
| **身份只对一个角色** | 「我此刻是」菜单顶部切到「只对某某」 | chip 上出现虚线的「仅此角色」，别的角色不受影响 |

| **改人设中途生效**（第八轮）| 聊几轮之后改主角条目 `index.md`，或在编辑抽屉里改「扮演指令」 | 同上——提示要亮，刷新之后模型行为要跟着变 |
| **自定义身份**（第八轮）| 「我此刻是」→「自定义身份」，写一句话确认 | chip 显示「自定义身份」；重开应用后仍在（进了 `agents.json`） |
| **角色回看自己说过的话**（第八轮）| 聊过 30 轮之后问「你还记得我们第一次说的那句话吗」 | 角色走 `search_conversation` → `read_conversation` 答出原话；执行日志里**不该**出现 `search_text` 或对 `read_file` 的调用 |
| **角色读不到别人的对话**（第八轮）| 让角色 A 去搜只在角色 B 那一场说过的词 | 答「没有」，且日志里没有任何跨 agent 的读取 |
| **模型两级** | 标题栏的「本角色」选择器 | 不绑时显示全局那个 + 虚线「跟随全局」签；菜单底部能「跟随全局设置」撤销 |
| **新开会话 / 存档** | 转场后从稿面顶端「已封存 N 场 · 查看」翻回去 | 旧场次原文都在 |
| **记忆区浏览** | 记事本 → 浏览全部 | 斜纹带、横格纸、搜索、改正文/关键字、手写一条、删除 |
| **队列** | 同时给 4 个 agent 发消息 | 第 4 个显示「排队中 · 插到最前 / 取消排队」 |
| **子代理看图** | 纯文本模型 + 开着识图子代理时发图 | 角色仍然「看得见」（走 delegate） |
| **旁白 scene 工具逐个** | 让旁白检索跨场次的内容、读某一场的某几轮 | 分页续读、跨场检索都对 |
| **旁白写正文** | 让旁白把某段互动改写并提交 | 审批卡落在**旁白自己的面板**里 |

## 3.5 场次记忆与旁白归档（第九轮，#354–#359）

设计见 [13-scene-memory-and-narrator-archive-plan.md](13-scene-memory-and-narrator-archive-plan.md)。
**下面这些单测证明不了**——它们问的要么是模型的行为，要么是运行中途的时序。

先把场景搭出来：拿一个角色聊够两三场，其中**至少一场走「接续」**、**至少一场走
「另起一场」**，这样才试得出两支的差别。

| 试什么 | 怎么问 | 对了是什么样 |
|---|---|---|
| **旁白找旧场次的事** | 转过两三场之后问旁白「和 XX 之前在雪原上那件事，是怎么回事」 | 它先 `list_scenes` / `search_scenes`，定位到某一场，再引用**原话**。答不上来或凭当前这一场瞎猜就是没做到 |
| **转述也能找到**（关键） | 用**你自己的话**问，故意不使用当时说过的词——「他俩上次闹掰那回」 | 索引层（场次前情 / 记忆区关键字）命中。逐字层这时一个字都对不上，所以这条才是真正的考题 |
| **只有另起一场的项目** | 一直点「另起一场」（从来不生成前情）的角色，问旁白「上周那次聊了什么」 | 没有任何摘要可用，旁白靠**日期**找到那一场 |
| **作废的场次不被当情节** | 在一个试验场里演一段很出戏的东西 → 「另起一场」→ 让旁白「把最近发生的事整理进正文」 | 那一段**不出现**在正文里，旁白也不主动提它。点名要求「把上次那个试验场翻出来」时才读得到，且带作废提示 |
| **丢弃是真的丢** | 试验场里让角色 `remember` 一件大事 → 「另起一场」→ 再聊两场，找机会提那件事 | 角色不记得。记事本里那条不在了，记忆区里也没有它 |
| **接续不受牵连** | 同一个角色更早场次记下的**未了结约定**，在「另起一场」之后 | 仍然在记事本里、仍然在上下文里。丢的是本场，不是全部 |
| **旁白读得到运行中途的新话**（时序） | 让旁白开始一次较长的整理，**在它跑着的时候**切去和某个角色聊三轮，回来接着让旁白读那个角色 | 它读得到那三轮。读不到 = 归档缓存把当前 transcript 一起缓存了 |
| **运行中途转场**（时序） | 旁白跑着的时候给另一个角色做一次转场 | 旁白下一次 `list_scenes` 看得见新封存的那一场 |
| **记忆细节按需展开**（风险最高） | 问角色一件它记过、但细节很长的事的**具体内容** | 它调 `recall` 取出正文再答。**凭标题编内容就是这一片没做到**——扮演只有 5 轮预算，退路（按 kind 分级）写在计划文档 PR3 里 |
| **角色回看自己的旧场次** | 转过场之后问角色「你还记得我们在雪原上说的话吗」（那句话在上一场） | 它 `search_conversation` 跨场找到并读出原话。只答「记不清了」＝ 没跨场 |
| **角色读不到自己的废弃场次** | 试验场里说过一句很特别的话，作废之后问角色 | 它不知道。日志里也不该出现对那一场的任何读取 |
| **导演视角**（默认档） | 身份选「导演」，写一句纯舞台指示：「天开始下雨，她推门进来」 | 角色**演下去**（让雨下、让人进门），而不是回应「谁在说话？」 |
| **陌生人那一档** | 切到「陌生人」，同样写那句话 | 回到改动之前的行为：把你当成戏里一个它还不认识的人 |
| **切换身份要亮提示**（最容易装错） | 在「导演」和「陌生人」之间来回切 | **「设定已更新」要亮**，点「刷新设定」之后模型行为跟着变。不亮 = `personaKey` 没区分两档 |
| **场号口径一致** | 手动删掉 `archive/transcript-02.md`，再看稿面顶端和转场卡说的「第 N 场」 | 两处说的是同一个数（最大编号 + 1，不是文件个数），新记的记忆里 `scene` 也是那个数 |

## 4. 待办

### 4.1 挂着，等一个前提

| 事 | 卡在哪 |
|---|---|
| **场次分隔线**（`第 4 场 · 晨 · 码头`） | 要「场」的**名字和时间**。只有场号的话，它和正上方那条带说的是同一件事 |
| **AI 优化记忆区**（合并重复、补关键字） | 先让它长出来，再谈整理 |
| **命中统计**（「近 10 场命中 3 次」） | 要一张跨会话的命中流水表 |
| **「不一致」提示** | 要拿记忆区比对项目知识库。结论是「留着」，所以价值全在提示本身，不该做个假的 |
| **「这轮不用」** | 它意味着**重跑这一轮**，是回退的近亲，不是提示条上的开关 |

### 4.2 明确判断不做

- **任务工作区入口**：扮演的工作区只为让 `delegate` 可用而存在，里面通常一个 note
  都没有；接它要先把 `TaskWorkspaceView` 参数化。为一个空目录做组件重构，不成比例。
- **执行日志摘要行**：它要的字段散在三处，而 `AgentLog` 已经把它们都渲染好了。

### 4.3 范围外

agent↔agent 对话、旁白写知识库、记忆自动提炼成知识库条目、群聊、语音。

## 5. 撞到问题时，这几件事对我最有用

1. **原话**：你问的那一句，和角色答的那一句。
2. **哪一层不对**：稿面（显示）、记事本（常驻层）、记忆区（史料层）——同一件事在
   三层里可能一层对两层错，而这决定了要查哪。
3. **`.ai-writer/roleplay/` 下的文件**：`transcript.md` / `memory.md` /
   `areas/*/history/*/index.md`。**盘上的东西才是真相**，界面只是它的一个视图——
   §2.10 那次就是界面对了而盘上（严格说是发给模型的）不对。
