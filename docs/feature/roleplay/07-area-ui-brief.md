## 0. 这是什么应用

一个桌面写作应用（Tauri + React），面向小说 / 跑团 / 剧本作者。视觉语言是
**「手稿」**：深色墨底或浅色纸面，衬线正文，单一赭石色作为唯一强调色，
**全局零圆角**（圆形只用于头像和状态点），层级靠背景深度 + 1px 细线表达，不靠
阴影和描边堆叠。

已有的扮演界面是同一个 Figma/Design 文件里的 **TURN 1（屏 1a–1i）**，请在它的基础上
延续，不要另起一套。TURN 1 已实现并在用。

**已有的关键词汇，请沿用：**

- 作者的回合 = 2px 赭石左规 + 全大写字距很开的小号名标（9px）

- 四种输入标记各有排版：`*动作*` 斜体、`「台词」` 更大更重、裸文本=场景、`[元指令]` 整块下沉

- 记事本里的记录卡：标题 + 正文 + 一行动作（已兑现 / 已作废 / 跳到第 N 轮）

## 2. 这一期要加的东西（功能背景，读一遍就够）

**转场。** 「新开会话」现在是一刀切的归档。改成两支：

- **另起一场** —— 和上一场无关。整场封存，可选「同时清空记忆」。
- **接续** —— 换了个地方继续（客厅 → 卧室）。上一场的**细节**不再需要，但要留下一份
  **前情**。作者可以写一句摘要侧重（「重点记下和塔有关的」），留空则模型自行判断。

**记忆区。** 每个角色有一个**独立的知识区**，格式和项目知识库一样（条目 + 关键字），
但**只属于这个角色**。旧的前情、了结的约定、零碎史料都归档到这里，靠关键字在相关
时自动出现。它可以被作者查看、编辑、优化，而且**可以被继承**——删掉一个角色，
记忆区还在，建新角色绑上它就接上了。

**记忆分两层**，作者需要看得出区别：

| 层 | 含义 | 一句话 |
|---|---|---|
| **常驻** | 约定 / 待办 / 关系 / 最新一条前情 | 每一轮都在，不需要被提起 |
| **记忆区** | 旧前情 / 已了结的 / 零碎史料 | 相关时才出现 |

## 3. 需要设计的屏

### 屏 2a · 转场对话框

替换现在编辑抽屉 footer 里那条就地确认条。它现在要承载一个二选一 + 一个输入框，
一行装不下了。

要表达的：
- 两支的**区别**要一眼看懂（关键差异是「前情留不留」，不是「归不归档」——两边都归档）
- 「接续」选中时才出现摘要侧重输入框（占位提示：留空则由角色自己决定记住什么）
- 「另起一场」选中时才出现「同时清空记忆」勾选项
- 当前这一场的规模（「18 轮」）应当可见——作者要知道自己在封存多大一块
- 一句话说明「对话不会被删除，移进存档，可随时翻阅」

**注意**：这是一个作者会反复用的操作（一天可能好几次），不要设计成一个郑重其事的
大模态。

### 屏 2b · 摘要生成中 / 摘要预览

接续时会跑一次模型。要有一个进行态，以及**结果的确认**——这份前情会成为角色接下来
的记忆，作者应当有机会看一眼、改一改再落地，而不是直接写进去。

可编辑的字段：标题、正文、**关键字**（日后靠它被命中，所以要可见可改）。

### 屏 2c · 记事本面板的两层视图

现在的记事本是一列记录卡。要加入「记忆区」这一层，并让两层的**区别**成立：

- 常驻层：现在这套记录卡不变
- 记忆区：条目列表（名字 + 关键字 + 一句话），点进去能看全文
- 需要一个入口通往「完整的记忆区浏览」（屏 2d）
- 两层之间是**降级**关系（转场时常驻的东西会沉下去），如果能在视觉上暗示这个方向
  最好

面板宽度约 300px，请在这个宽度内工作。

### 屏 2d · 记忆区浏览 / 编辑

一个和「知识库」很像但**必须一眼看出不是它**的界面——这是**某个角色以为的事**，
不是世界的事实。它可能和正典矛盾，而那是特性。

需要：条目列表、搜索、关键字的编辑、条目正文的查看/编辑、这个区属于谁、共多少条。

参考已有的知识库墙（格纸背景、硬阴影卡片、按分类着色），但**要有明确的区隔标记**。

### 屏 2e · 创建 / 编辑角色时绑定记忆区

现在的编辑抽屉（760px）已有：类型、主角条目、绑定设定、模型、指令、footer。
要加一节「记忆区」：

- 新建一个 / 绑定一个已存在的（列表里显示名字 + 条目数 + 上一个使用者）
- 强调**继承**：绑定一个已存在的记忆区意味着这个角色继承了那些知识
- 一个记忆区同时只能被一个角色绑定 —— 已被占用的要显示出来

### 屏 2f · 新一场开头的「前情」

接续之后，新的一场从空白开始，但角色带着前情。稿面顶端需要一条**前情提要**——
它不是一轮对话，是这一场的起点。

现在稿面顶端已经有一条「此前已封存 N 场 · 查看」的细线小字，两者要能共存
（或者合并成一个更好的东西）。

### 屏 2g · 记忆区被命中时的痕迹

某一轮里，角色的某条旧记忆因为关键字被自动带进了上下文。作者应当能看到这件事
——否则角色突然提起三场之前的事，会像是幻觉。

参考：现在角色记下东西时，回复下方会有一道很轻的痕迹（「记下了：…」）。这个要
同一个量级——**不能像系统通知那样打断阅读，但也不能轻到看不见**。

## 4. 约束

- **全局零圆角**，圆形只给头像和状态点
- 单一赭石强调色，不要引入第二个彩色
- **深浅两套主题都要出**
- 稿面正文栏固定 640px 是不让步的一条；挤不下时先让花名册（已有一套 56px 头像轨的
  窄布局）
- 中文优先，界面文案用中文
- 不要引入新的圆角 / 阴影层级 / 渐变；层级靠背景深度和 1px 细线

## 5. 一句话概括这一期的用户价值

**换个地方继续演，角色不会失忆；演了三十场之后，它仍然能想起第三场发生过什么。**
