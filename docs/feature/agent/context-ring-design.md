# 上下文圆环与归纳入口

> Status: `shipped`. 2026-11-04。分段圆环已接入正式对话助手。设计原型：`/#context-ring`；正式组件的隔离验收：`/#context-ring-live`。

## 目的与布局

移除对话助手输入框上方独占一行的 ContextBar，将入口放到输入框底部「片段」右侧，间距 8px。20px SVG 环放进 32px 按钮；常态不显示数字，减少噪声。圆环属于计量指示器，浮层及按钮继续使用项目方角和主题令牌。

环表示已使用输入 / 可用输入上限，不使用模型总窗口作分母。截图示例约 28.7k / 839k = 3%；1,049k 是模型总窗口，在详情另列。总用量数据沿用 contextBreakdown；原型分项为虚构数据。生产接入时必须保留现有全部分项及 raisedFromTokens、foldDeferred、stateMode 等解释，不重算预算。

## 交互

- 悬停显示用量与占比。Enter / Space 或点击打开上方浮层，不推动输入区布局。
- 浮层宽 320px，显示占比、用量、各项构成、可用输入上限、模型总窗口、自动归纳状态。可用高度不足时内部滚动，生产接入用 portal 和视口碰撞定位。
- Esc、再次点击或点外部关闭；Esc / 关闭按钮归还入口焦点，Tab 可顺序经过操作并离开浮层。
- 「立即归纳 · Compact」是底部唯一主要操作。说明将较早对话整理为摘要，保留近期对话，并提示摘要可能省略细节及模型计费。
- 归纳中禁用重复操作；可关闭详情，重开仍显示当前状态。成功更新读数，失败保留原上下文并可重试。
- 当前回复未结束时禁用归纳，并显示原因；无可折叠历史时禁用并说明。状态记忆模式沿用「更新状态」语义。
- 新会话显示空环并说明发送后才有用量；未知窗口显示问号虚环，不伪造百分比。

## 告警与实现边界

原型高用量场景固定 89%，以警告令牌演示。正式组件必须使用现有 `willCompact && autoCompact || over` 告警语义，不能把 85% 写成新业务阈值。超过上限圆环视觉钳制在满环，文本仍显示真实百分比；无法通过归纳解决的超限必须明确解释。

初始设计针对对话助手；经追加确认，扮演页也采用同一入口（见下方扩展记录）。原型自动归纳勾选、用量与延迟均为内存演示，不写偏好、不调用模型。静态片段与发送符号只是布局参照；消息框可输入但不发送。

## 验收

宽窄布局、浅深主题、键盘焦点、低动态偏好，以及正常 / 高用量 / 空会话 / 运行中 / 未知窗口 / 失败重试都应可检查。正式实现另外验证多会话切换期间归纳归属与发送互斥。设计确认后才进入生产组件。

## 本轮验证

原型类型检查、构建及文档引用/状态护栏通过。浏览器已检查宽版浅色、窄版浅深色、详情开合、Esc 与模拟归纳完成读数。未逐一完成所有异常场景及低动态系统偏好的浏览器验收；原型没有动画。

## 分段配色调整 — 2026-11-04

按作者反馈，圆环从顶部顺时针依次显示系统与工具、摘要、种子、注入条目、对话，剩余部分为轨道底色。完全沿用现有 ContextBar 的五个语义颜色令牌；详情的条形图及方形色标使用同一组数据和颜色。高用量只在按钮外围提示告警，不将全部分段染成警告色，以免丢失内容构成。

每段严格按输入上限占比绘制，不为小分段强行加最小角度，也不加会吞掉小段的间隙。截图的 3% 占用下各色段很细是正确表现，可点击查看明细；切到「接近上限」场景可审查完整分段配色。高用量演示分项合计 746.7k，正常演示合计 28.7k。


## 正式改造计划 — 2026-11-04

### 1. 范围与完成标准

仅改造对话助手 AgentChat 的上下文入口，覆盖普通、生成中、等待审批三种状态；移除输入区顶部原计量条，在两个 inputFooter 分支的片段右侧加入圆环。等待审批时圆环仍可查看，不能放入片段所在的 `footerInert` / `aria-hidden` 容器。详情打开不改变正文与输入框高度。

继续使用现有预算计算、归纳算法、历史持久化和用量入口。扮演页按追加确认改用圆环；最后一个调用方迁移后删除旧 ContextBar。自动归纳状态在详情只读，原型的切换控件属于演示工具，不变成新的偏好入口。无需新增偏好或数据库迁移。

### 2. 组件与数据接入

- 新增 `src/components/ai/ContextRing.tsx` 与对应 CSS Module，负责按钮、分段 SVG、详情浮层和操作反馈。
- 使用 AgentChat 已有 `context`、`activeKey`、归纳中状态及会话忙碌信息，继续由 `computeContextBreakdown` 提供数值。不搬入原型数据、计时器和固定 85% 阈值。
- 直接消费 `CONTEXT_SEGMENT_ORDER`，各段长度使用未取整比例；总读数单独格式化。正常按输入上限为分母，超限时绘制按实际总量缩放为满环，读数仍显示真实超限比例。零值不绘制；未知容量不绘制伪造比例。
- 五类颜色逐项复用 ContextBar 的现有令牌。浮层明细保留五类与空余，不把摘要、种子、注入内容合并。文字通过双语 locale 与 `useTerms()`；未知窗口、超限等状态有文字说明，不依赖颜色。
- 将适合共享的标签、Token 格式化与详情说明抽成小型展示模块，确保新环与旧条的 `raisedFromTokens`、`foldDeferred`、`stateMode`、自动归纳关闭等解释不会分叉。扮演预估由同一圆环承载，保留独立的下界语义。
- 新会话依据真实历史判定，并检查现有 breakdown 是否已计入系统/工具成本；有成本就显示已有估算，不能因为会话为空强行把用量归零。原型空环仅是无可计量数据的示意。

### 3. 浮层与键盘

浮层通过 portal 挂到 body，优先向上展开并与触发区对齐，宽 320px；横向钳制在视口安全边距内，高度按可用空间限制并内部滚动。监听窗口缩放、容器滚动及触发器尺寸变化；输入区缩放不让浮层悬在旧位置。

检查复用 `usePopoverDismiss` 的方式：现有 hook 只判断单一 root，不能直接用于 portal。新增支持触发器与浮层两个 ref 的关闭逻辑，或以兼容方式扩展 hook 并回归旧调用方。Esc 在捕获阶段消费，防止同时关闭 AI 抽屉。外部点击不抢回焦点；Esc / 关闭按钮返回入口。Tab 可进入操作区并继续离开，无焦点陷阱；点击归纳后按钮变 disabled 不得误关浮层。会话切换和所属面板卸载时关闭浮层。

20px 圆环、32px 点击区、8px 与片段间距；保留现有焦点令牌。低用量不夸大弧长；高用量只强化外围告警，保留分类配色。无需持续旋转或占比跳动动画。

### 4. Compact 状态与结果

现有 `compactChatNow(key?)` 已按会话记录 `compactingChats`，并负责历史替换、contextVersion 更新、事件日志、持久化及队列唤醒。继续复用此路径，不由组件直接请求模型。

- 在 `src/stores/agent/types.ts` 定义明确的操作结果：成功、失败、跳过、取消；为跳过携带忙碌/无可归纳内容/会话缺失等原因。同步 `agentStore.ts` 的各条返回路径，保留现有错误呈现与日志行为。
- 成功/失败反馈按 chatKey 保存为短期内存状态，并用请求标识隔离旧结果；浮层关闭或组件卸载不丢失当前归纳状态。新会话、删除会话、项目切换及 reset 时清理对应记录，不加偏好持久化。与已有 `compactingChats` 保持一个执行事实来源。
- 点击时显式传入当前会话 key，不依赖异步完成时的 activeChatKey。采用已有 `ownerBusy` 语义，包含运行、归纳和队列占用；具体禁用原因可读。store 仍作最终校验。
- 归纳中禁止重复点击；发送互斥沿用现有路径。成功后展示真实前后读数，不承诺固定节省比例，也不将未执行误报成功；再次归纳是否可用由最新 `canFold` 决定，不永久禁用。
- 失败显示该次归纳的错误摘要与重试入口，不能把历史上的任意聊天错误当作本次归纳失败。取消不报失败；重试重新检查资格。
- 状态记忆模式使用「更新状态」及对应解释、结果文案。保留原有失败恢复和协议配对修复语义，不把“原对话保持不变”扩大为字节级不变承诺。

| 数值与分段 | 0、3%、高占用、100%、超限、未知窗口；各段合计一致，无负角度/NaN，颜色与旧条一致 |

6. 更新 design-system、codemap 和本记录为交付事实，docs/README 状态同步；PR 指向 main，CI 绿后交由作者合并。
