# 生成页空间与层级重构

> 状态：`shipped`。2026-11-04 原型获作者确认，生产 AiPanel 已按方案改造，待合并。

## 意图与布局

把任务按钮墙缩为当前任务名称、来源和更换入口。任务选择在限高、可搜索的弹窗中按通用任务与工作台分组，选择后关闭。当前任务始终可见。

任务配置默认展开，以标题、边框与轻底色划出边界。生成版本、参考上文归回适用任务；续写显示长度、位置与写作方向。模型思考参数移入默认收起的运行设置，收起显示有效值。上下文分配通过执行栏圆环查看，明确是本次输入预估，不出现 Compact。

参考资料默认显示自动匹配状态、已固定数量和最多两项标签。原「指定条目」改为「固定引用」，通过管理弹窗搜索和选择，不占主表单长列表。解释自动匹配仍会发生、引用不等于输出目标、选择在正式产品中按项目保留。预算藏进该弹窗的详情。补充材料属于资料，补充要求属于任务。

## 原型范围

入口 `/#generate-workspace`。使用静态任务与资料样本，状态只在组件内，不读项目、不持久化、不调用模型。续写与重写/润色展示不同参数布局，其他任务为简化的要求输入。支持任务搜索切换、引用勾选/移除/已选筛选、要求输入、运行设置、预算详情、超限阻断和固定示例输出。包含 360px 窄栏预览与工作台主题选择。

不模拟真实文件写入、审批、任务执行和计费。特征级选择、前情提要更新、开篇承接文档、多版本结果比较留待正式实现时按现有行为接入。

## 验收点

- 任务数量增加不改变主页面高度；关闭选择器仍能看清当前任务和来源。
- 参考上文与生成版本属于任务配置；任务切换保留各任务的要求文字。
- 引用未选择不意味着禁用自动匹配。管理器关闭后数量与标签同步。
- 模型设置收起仍能看见思考力度。预估超限直接提示，实际请求仍由运行时检查。
- 宽面板左右双栏，窄面板单列；弹窗支持 Esc、关闭和焦点返回。无动画依赖，适配 reduced-motion。
- 本原型获确认后再改生产组件；不在本次原型工作中开功能 PR 或递增版本。

## 正式实现与取舍

作者于 2026-11-04 确认实施。`AiPanel` 使用原生模态 `GenerateDialog` 承载任务、引用与预算详情，避免长列表挤占表单；浏览器负责模态焦点限制，关闭返回触发器。弹窗键盘事件不冒泡到 AiPanel，避免搜索时 Cmd/Ctrl+Enter 执行底层任务；Esc 遵守输入法组合状态。任务与引用列表仍使用真实能力包、条目及特征数据。引用摘要按条目计数，标签移除同时移除该条目的全部特征固定引用；管理器保留特征级操作、已选筛选和预算设置。

任务要求改为 composerStore 中按任务 ID 存放的未发送草稿，切换任务与关闭抽屉不会丢失；切换项目按原有 resetAll 清空。生成版本、参考上文只按任务能力显示，回归任务配置区域。附加知识移到参考资料旁；开篇承接、前情提要、批处理与输出审批继续走原逻辑。

运行设置复用 `ReasoningControls` 的 footer 控件，收起显示模型的实际有效值，展开注明修改模型配置；系统提示词选择放入更多设置（没有可选项时不显示空折叠区）。圆环复用生成 forecast 的原有六段与颜色，表示预算分配预估，不假装是聊天实测用量，因此没有 Compact。预计超限在主面板直接提示，但不禁用执行：forecast 会预留可能不存在的前文原文和概要，不能将分配预估等同于组装后的实际输入。实际请求继续由运行时预检。上下文设置跳转先关闭预算对话框。

窄于 700px 的面板改为单列可滚动布局；断点按面板宽度而非窗口宽度，防止宽窗口中的窄抽屉仍挤成双栏。引用管理、预算详情使用模态而不是锚定浮层，原因是特征列表和预算说明需要可用高度，窄栏中也可读。

独立验收入口 `/generate-live.html` 渲染正式组件，只有内存样本，任务执行替换为空操作，不连接项目或供应商。原 `/#generate-workspace` 保留为批准的设计参照。

## PR 审查修复

- 预估包含尚未读取的前文预留，且与实际装配存在任务能力差异，不能作为新的硬性执行门槛。改为警告，保留原有运行时检查，避免独立开篇、小窗口模型等可运行请求被 UI 误挡。
- 窄栏下配置列不再成为执行栏的定位边界；执行/停止栏排在共同滚动区末尾并吸附底部，滚动查看长结果时仍可停止。
- 固定引用适用于所有任务；任务要求也不依赖 referenceWindow。统一构造 extras，只有参考上文字数按该能力开关传入，避免工作台任务显示了参数却丢弃输入。增加覆盖普通工作台任务、自由指令、续写和零参考窗口的回归测试。
