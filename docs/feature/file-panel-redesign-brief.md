# 「文件」面板重做 —— 设计任务书

请在设计项目里**新开一个文件 `17 文件面板 Files Panel`**（而不是改 `01 工作区`）。
`01` 画过这块，但那是最早的一轮，之后面板长出了多选、拖拽移动/复制、剪贴板、
文件夹章数、内联新建/重命名等等。**凡是你推翻 `01` 的地方，请在说明栏里点名指出**，
我实现时要拿它和旧稿对账。

面板的**未打开项目**态（最近打开 / 已固定）已在 `15 固定最近项目` 定过并已实现，
**本期不动**。本期只做「已经打开一个项目之后」的这块面板。

## 0. 这是什么应用

桌面写作应用（Tauri + React），面向小说 / 跑团 / 文案 / 周报 / 标书作者。视觉语言是
**「手稿」**：深色墨底或浅色纸面，衬线正文，**单一赭石色**（`--color-accent`
浅 `#A0522D` / 深 `#D9925B`）是唯一强调色，**全局零圆角**（圆形只留给状态点、头像、
spinner），层级靠背景深度 + 1px 细线，不靠描边和阴影堆叠。侧栏是玻璃 chrome
（`--glass-bg-strong` + 模糊）。悬停用**中性底** `--color-bg-hover`，**选中**才用赭石
tint —— 把悬停也染成赭石会读成一个并不存在的选中态。

## 1. 这块面板现在是什么

**它是一个文件管理器，不是章节列表。** 工作区就是整个项目文件夹，作者可以随意组织；
早期项目里那个 `writing/` 文件夹如今只是一个普通目录。因此这棵树支持：多选
（⌘/Ctrl 点、⇧ 范围）、拖拽移动、按住 ⌥ 拖拽复制、剪切/复制/粘贴、内联新建与重命名、
删除（先进 `.ai-writer/backups` 快照）、拖拽悬停 700ms 自动展开、把条目拖到树的**空白
区**＝移回项目根。

## 2. 要你解决的问题

### 2a · 顶部四层吃掉 216px

项目头（眉标 + 项目名 + 三个计数）· 搜索框 · 「文件」节标题 · 工具栏 —— 四层各自
带 padding，第一行文件出现在 **≈216px** 处，240×800 的面板里是 27%、约 7.7 行。

请重新分配这四层：哪些合并（比如节标题「DOCUMENTS · 文档」和工具栏本就该是同一行的两半）、哪些沉进别处、
哪些只在滚动到顶时出现。**约束**：项目名要留（多开窗口时它是唯一的区分）；三个计数
（字数 / 文档数 / 条目数）可以降级但不要删；搜索框点了其实是开命令面板（⌘K），它
不是一个真的输入框 —— 如果你觉得它不该长成输入框的样子，请直说并给出替代。

### 2b · 一排图标按钮已经放不下，而这期还要再加一个

7 个按钮需要 166px，面板最窄（160px）时只有 116px 可用，图标已经在被压扁。本期还要
加**「全部折叠」**（见 2c）。请给出一套能长期活下去的方案，比如：分组 + 分隔；
高频三个常驻、其余进一个 `⋯` 溢出菜单；按面板宽度分档隐藏；或者把项目级的三个
（切换项目 / 新窗口 / 关闭项目）整体挪走（它们不是「对树的操作」）。

请顺带定：这排按钮**要不要在面板未被 hover 时淡出**？（它一直亮着，而作者 99% 的
时间是在读下面的树。）

### 2c · 「全部折叠」是本期的直接需求

作者的原话是：文件树需要一个「全部折叠」按钮，把所有子目录收起来。请给出它的位置、
图标、禁用态（树里没有目录、或已经全部折叠时）、以及按下之后的**反馈**——树一瞬间
从 40 行变成 5 行，没有任何过渡的话像是数据丢了。（实现侧已定：**不做动画**，一次
卸载上百行是全场最贵的一次布局；所以反馈只能来自按钮自身或一条静态提示，不能来自
行的高度动画。）

两件相关的、请一并拿主意：
- 按下之后，**当前打开的那个文档**也会被藏进折叠的文件夹里（实现侧已决定不给它开
  特例，否则按钮就变成「折叠除了…之外的全部」）。要不要配一个**「定位当前文档」**
  的记号或按钮？如果要，它长什么样、放哪。
- 折叠会把**选中但已不可见**的行留在选区里。实现侧的处置是把选区收敛到可见行。
  这需要一个视觉说法吗（比如折叠瞬间选区记号的收束），还是静默即可？

### 2d · 悬停 / 多选 / 当前打开，现在是同一个底色

`hover`、`selected`、`active` 三态都用 `--color-bg-elevated`，只有「当前打开」多一条
2px 赭石竖线。于是「我选中了 5 行」和「鼠标正划过一行」长得一样，而这个面板的删除、
移动、复制**都作用于选区**。

请重新拆这三态（外加它们的**组合**：一个被选中的行同时是当前打开的文档；鼠标悬停在
一个已选中的行上）。设计系统的既定规则是**悬停中性、选中赭石 tint**，但选中在这里
可能有 20 行，20 行赭石 tint 会很吵 —— 这正是要你判断的地方。**几何往往比颜色能表达
更多状态，而这个应用只有一个强调色**（这条经验来自 `12 写手` 那一稿的署名竖线）。

### 2e · 一行 28px 里塞了五样东西，且互相打架

现在的处置是：鼠标一进入这一行，**章数就整个消失**，给两个动作按钮让位。于是作者想
对比两个文件夹的篇数时，鼠标扫过去数字就没了。

请定：一行里谁常驻、谁 hover 才出现、窄档（160px，第 3 层缩进后名字只剩 ~130px）
先牺牲谁。也请判断那两个 hover 动作按钮（在这个文件夹里新建文件 / 新建文件夹）是不是
还该留在行上 —— 右键菜单里已经有同样两项。

### 2f · 拖拽 / 剪贴板那一整套状态记号各自为政

1.2 那张表里的九种记号是分几次长出来的：一个用透明度、一个用 inset 框、一个用左边线、
一个用实心徽标。请给它们一套**统一的记号语言**，并明确回答：

- 拖到两行**之间**（重新排序 / 插到某一层）现在**不支持**，只能拖到文件夹**上面**。
  你的设计里要不要出现一条插入线？如果画了，我就得实现它，请确认这是你的意图。
- 多选拖拽时，那 5 行本身怎么表示「正在被搬走」（现在是各自 `opacity: .4`）。
- 「已剪切、等着粘贴」这个态会**跨面板存活**（切到大纲页再切回来还在），它需要比
  `opacity: .45` 更明确的说法吗？

### 2g · 文件种类的表达

树里会出现：`.md`（正文，后缀在界面里被吃掉）· `.txt` · `.html`（**AI 写出来的
可交付物**，能预览、能导成 PPTX）· 图片 · `.docx/.pdf/.pptx/.xlsx`（导入时会转成

自己维护）。现在只有 4 种 lucide 图标、一种灰色。

请判断：要不要把「AI 产出物」「附件目录」「导入的原件」在视觉上分出来？还是保持
克制、只靠图标？（倾向克制 —— 但 `assets/` 目录被作者手工改名会**打断文档里的图片
链接**，这一条也许值得一个极轻的记号。）

### 2h · 两个极端宽度与大项目

- **160px**：缩进吃掉 3 层之后名字只剩一百多像素。先牺牲什么？
- **500px**：多出来的 260px 是留白，还是让位给某样常驻的东西（比如章数常驻、路径、

- **几百个文件、七八层深**：树是**全量渲染**的（没有虚拟滚动）。请不要设计任何

## 3. 数据边界（请不要设计出画不出来的东西）

树里每个节点**只有** `{名字, 路径, 是否目录, 子节点}`。具体说：

- **没有**修改时间、文件大小、创建时间。
- **没有**单个文档的字数。只有**当前打开的那一个**有实时字数（在项目头的计数里）。
  文件夹右侧的「章数」是它下面任意深度的 `.md` 文件**篇数**（已有，很便宜）。
- **没有** git 状态、没有云同步状态（知识库同步只同步知识库，不同步文档）。
- **没有**文件级的收藏/固定（「固定」目前只属于最近打开的**项目**，见 `15` 稿）。
- 隐藏文件（点开头）和 `.ai-writer/` 根本不在树里。
- 「选中」和「打开」是两件事：多选可以有 20 行，当前打开的文档只有一个。
- 文件夹的展开状态**不跨会话保留**（关掉项目就回到默认：顶层展开、深层折叠）。

如果你的设计需要上面某样不存在的东西，**请单独列出来**并说明它值不值得 —— 我会评估
数据层的代价，而不是默默砍掉你的设计（过去有几轮就是这么丢掉功能的）。

## 4. 必须遵守的约束

- **零圆角**；唯一强调色赭石；悬停中性、选中赭石 tint（2d 可以推翻这一条，但要说明）。
- 颜色一律标 **token 名**（`--color-text-faint`、`--color-border-soft`、
  `--color-bg-elevated`、`--color-accent-tint`…），不要给裸十六进制；确实需要新颜色时
  说明它映射到既有的哪个角色，并**同时给浅/深两套**。
- 动效 120–320ms + Apple 缓动，`prefers-reduced-motion` 下退化。行级的悬停/按压是
  **纯 CSS**（这个应用只在整屏切换和浮层进出时用 JS 动画库）。**树的展开/折叠现在
  没有高度过渡，本期也不打算加**（见 2c）。
- 不弹模态做确认；应用惯例是**就地展开的确认条**。
- 图标全部来自 **lucide**。
- 面板是玻璃 chrome，行**通铺到容器边缘**（当前打开那条赭石竖线要贴到最左边），
  缩进靠行内 padding，不靠外边距。
