## 设计稿改了方案的三处

1. **菜单文案**「转写为文字」→ **「转写为文字稿…」**（省略号 = 会出卡；「文字稿」比「文字」更像一份产物）。采纳。
2. **单价的货币**：方案 §4 写的是「作者填折算后的美元、标签 `$ / 秒`」；设计稿全用 ¥ 并把汇率问题挑明。**部分采纳**：抽屉里标签写 `¥ / 秒`、估价显示 ¥，但存进 `token_usage.cost_usd` 的仍是这个数——也就是说用量页那一列在转写行上其实是人民币。这是已知的账目不一致，记进 `01-execution-plan.md` §4 的开放问题，PR 2 不解决（用量页记两种货币是另一片）。
3. **失败态的「重试」**：方案没写；设计稿在文件树痕迹和审批卡上都给了。采纳——重试就是再走一遍确认 / 审批（缓存会让读过的文件不付第二次）。

# 设计任务：在本项目里新建 `02f 音频转写 Transcribe.dc.html`

## 这一屏是什么

作者把一段录音（采访、口述、会议、一集播客）或一段视频丢进项目，右键它，旁边就多出一份带时间戳的文字稿；或者在对话里对助手说「把这段采访转成文字」，助手出一张卡，作者点头，它去做。转写不在本机跑——文件会上传到阿里云的临时存储（48 小时后自动清理），由千问的录音文件识别模型处理，**按音频秒数计费**（一小时约 ¥0.8）。整件事藏在 实验室 的一个 Beta 开关后面。

这次要画的不是一个新页面，是**四处小东西**长在已有的屏上：

1. `05b 设置 · AI 配置` 的 **实验室** 一行、**子代理** 一行；
2. `05c 模型编辑` 里多一种「转写模型格式」，选了它抽屉要**收缩**；
3. `01b 文件面板（一）` 的右键菜单多一项 + 一张**转写前的确认卡**，以及转写进行中那一行的样子；
4. `02a AI 面板` / `02b 助手多会话` 里助手发起转写时的**审批卡**（照 `convert_document` 那张卡的家族）。

其余背景直接看 `05b`（实验室 / 子代理两个 pane 的分节写法——日中翻译那一行就是这次最近的亲戚：一个 Beta 开关 + 一个只会干一件事的专用模型 + 子代理里的绑定）、`05c`（**虚线 = 未设置** 那条规矩，以及「翻译模型格式」段是怎么让抽屉别的段折起来的）、`01b`（右键菜单与「转换文档」那一项、行上的 busy 态）、`02a`（审批卡的家族：`convert_document` / `export_pptx` 那种「先看一眼再落盘」的卡）。不用重新解释产品。屏号从 `02f` 起是因为 `02e` 是归纳阈值。

## 这次要解决的五个张力

**1. 这是一个上传 + 付费的动作，但作者点的是「右键 → 转写」。**
右键菜单里的其他项（转换文档、导出 PPTX）都是本机、免费、可撤销的；这一项把作者的录音送到第三方、按秒扣钱、任务一提交就不能取消。所以转写前要一张**确认卡**，而不是直接跑。卡上要说清四件事：文件（名字、大小、能算出来就给时长和估价——mp3 算不出时长，只能给大小）、去哪里（「上传到阿里云临时存储，48 小时后自动清理」，这是隐私事实，要用陈述句写在卡上，不藏进 tooltip）、会写到哪（同目录 `采访.md`，同名加序号）、以及一个开关（说话人分离，默认关；开了多 2 秒、多一列「说话人 N」）。语气照 `05f 屏 1k`：陈述句、中性灰，**不用红、不用 ⚠**——这不是危险操作，只是不免费。确认按钮写动作不写「确定」：「上传并转写」。

**2. 转写进行中有三个阶段，作者只看得见一行。**
上传（秒级）→ 排队（通常 0–2 秒，偶尔更久）→ 识别（一分钟音频 2 秒，一小时音频没测过）。文件树那一行要有 busy 态（借 `01b` 转换文档那一行的），但标签要随阶段变：`上传中 · 2.4MB` → `排队中` → `识别中 · 第 3 次查询`。不要进度条——我们拿不到百分比，假进度条比没有更糟。结束时的痕迹用 `02c 提示词库` 那种赭石细线 + 一句话：「已转写 · 48 秒 · ¥0.01 · 采访.md」，1.6s 后淡出；失败时那句话换成原因（「上传失败」/「服务端未能读取文件」/「超时」），不淡出，点一下可重试。

**3. 一个「只会转写」的模型，怎么在模型抽屉里不像个残缺的模型。**
`05c` 已经有「翻译模型格式」这一段：选了 Sakura，抽屉会把思考 / 结构化输出 / 上下文探测这些段折掉。这次并列加「转写模型格式」，选项只有一个（`DashScope 录音文件识别`），选了之后**留下的只有两件**：模型 id（预填 `qwen-audio-3.0-asr-flash-filetrans`，可改）和每秒单价（`$ / 秒`，虚线＝没填＝用量页记不了钱，抽屉底部「将发送」那行要改说它发的是 `/services/audio/asr/transcription` 而不是对话端点）。折起来的段不要消失得像坏了——沿用 `05c` 已有的折叠语汇。同时这个模型**绝不出现**在任何「选一个模型来对话」的列表里（和翻译模型同一条规矩），子代理里只有「音频转写」那一行能选到它。

**4. 子代理那一行，有两个属于「输出」的开关。**
子代理 pane 里「音频转写」一行照日中翻译那一行的骨架：绑定的模型 + 启用开关 + 一行 mono 说明。但它还带两个偏好：**时间戳**（默认开，写在每段前面 `[03:12]`）和**说话人分离**（默认关）。它们是产物长什么样的偏好，不是能力开关，所以住这一行而不是实验室；确认卡上那个「说话人分离」开关是**本次**的临时值，默认值从这里来。要让作者看得出这两层关系，而不是两处各有一个看起来一样的开关。

**5. 助手发起时，卡片要在花钱之前，不能在之后。**
`convert_document` 的审批卡是「已经转好了，给你看一眼再落盘」；转写不能这样——转写本身就是要花钱的那一步。所以这张 `transcribe_audio` 的审批卡是「**要不要花这笔钱**」：文件、大小、估价、目的地、分离开关（沿用确认卡的那一组，同一件事两个入口长一样），批准后卡片本身变成进度（同张力 2 的三阶段），完成后卡片收成一行结果「已写入 采访.md · 48 秒 · 12 句」。拒绝的文案给模型看，不给作者看——作者拒绝就是拒绝了。

## 交付什么

一个 `.dc.html`，屏号 1a 起，浅 / 深两套 + 中 / 英，带设计说明侧栏：

- **1a** 实验室一行（关 / 开两态；开着时脚注「接着去 子代理 →」）+ 子代理「音频转写」一行（未绑定 / 已绑定 / 已绑定但模型被停用 三态；两个输出开关）。
- **1b** 模型抽屉：选「转写模型格式」前后两态；单价虚线未填态；「将发送」行。
- **1c** 文件树右键菜单（Beta 开、已绑模型；Beta 开、未绑模型＝禁用并指路「去子代理绑定模型」；Beta 关＝这一项**不存在**，画一张对照）+ 确认卡（mp3 算不出时长 / wav 算得出 两态）。
- **1d** 文件树那一行的三个阶段 + 完成痕迹 + 失败痕迹。
- **1e** 对话里的审批卡：待批准 / 进行中 / 完成 / 失败 四态。
- **1z** 决策注记：每个张力你怎么定的，尤其是确认卡与审批卡为什么长得一样（或者为什么不）。

## 数据边界（照实画，别画我们拿不到的）

- 时长：只有 wav 能在上传前从文件头算出来；mp3 / m4a / mp4 只有大小。估价 = 秒 × 单价，单价作者没填就没有估价，卡上那一格是虚线。
- 进度：没有百分比，只有阶段名和第几次查询。
- 结果：句数、总时长、有没有分出说话人、写到了哪个文件。**没有**准确率、没有置信度。
- 模型：一种格式、一个默认 id；没有"选一个模型"的下拉（子代理里已经绑了）。

## 不要做

- 不要做一个独立的「转写」页面或「音频库」——入口就是右键和对话。
- 不要在文件树里给音频文件加播放器或波形；这一轮只认它是一个能转写的文件。
- 不要把「上传到阿里云」做成弹窗警告；它是卡上的一句陈述。
- 不要给进行中的任务画「取消」——平台没有取消接口，任务提交了就会计费；作者能做的是不再等（关掉那一行的痕迹），实现上我们只停止轮询。
- 不要给确认卡加「不再提示」——每次都是一笔钱。
