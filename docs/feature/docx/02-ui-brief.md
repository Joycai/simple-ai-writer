# 设计任务：为一款桌面写作应用设计「Word 排版格式」

## 0. 这是什么应用

一个桌面写作应用（Tauri + React，Mac 和 Windows），面向小说 / 公文 / 标书 / 周报作者。左边文件树，中间 Markdown 编辑器，右边呼出一个很宽的 AI 抽屉。里面住着一个 AI 助手，它能读项目里的文件、能提出修改、每一次写盘都要作者在一张卡片上点批准。

现在要加一个 Beta 功能：**AI 助手可以把项目里的 Markdown 文档导出成 Word（.docx），并且严格按照一套指定的排版格式。**

## 1. 这个功能的真实使用场景（先读这个，它决定了设计的取向）

用户不是"想导出一个好看的 Word"。用户是**手上有一份甲方给的格式要求**：

> 正文使用仿宋_GB2312，三号字，行距固定值 28 磅，首行缩进 2 字符；
> 一级标题黑体二号居中；页边距上 37mm 下 35mm 左 28mm 右 26mm；
> 每页 22 行、每行 28 字。

他要做的事是**逐条核对**：我设的和要求的一样吗。核错一条，整份标书可能被判无效。

所以这个界面的第一性质是**规格核对表**，不是主题选择器。数字是主角，好看是配角 —— 这和绝大多数"选个排版风格"的 UI 的直觉恰好相反，请不要把它设计成一排漂亮的缩略图卡片让人挑。

**但它也不能是一张 30 行的 Excel。** 张力就在这里：既要让每一个数字都能被找到、被读准、被核对，又不能让人一打开就想关掉。

## 2. 三个必须被解决的具体问题

### 2.1 号数和磅必须同时出现

中文规格说"三号"，Word 的对话框显示"16"。作者手里的要求可能用任意一种写法。所以**每一处字号都要同时写两种**：`三号（16 磅）`。行距同理：`固定值 28 磅`，而不是孤零零一个 `28`。

行距有三种模式且不能混：**固定值 / 最小值 / 倍数**。规格写"固定值 28 磅"而设成"1.5 倍"是一个打印出来才会发现的错。这三态在界面上必须一眼可分。

### 2.2 中西文字体是两个独立的字段

中文排版里，同一段文字的汉字用一种字体（仿宋_GB2312），英文和数字用另一种（Times New Roman）。这**不是**一个"字体"下拉能表达的。

而且：**字体可能本机没装**。作者在 Mac 上大概率没有仿宋_GB2312 —— 导出的文件仍然是对的（拿到 Windows 上打印一样合规），但他本机预览时看到的是替换字体。这需要一个不吓人但不能忽略的提示。

### 2.3 "这次和平常不一样"必须看得见

作者平时用默认格式。偶尔一次他会说"这次用仿宋、行距 1.5 倍"。审批卡上必须让他一眼看出：**这次动了哪两条**。

## 3. 视觉规范（硬约束，必须遵守）

这个应用有严格的既定视觉语言，新界面必须无缝融入：

- **风格**：克制的、现代的、Apple 式的。整体气质是「手稿」—— 像裁切的纸，不像圆角卡片。
- **圆角：全局为 0。** 所有容器、按钮、输入框、下拉都是直角。唯一允许的圆形是状态圆点、加载指示器、单选标记。开关是方形的。
- **强调色：只有一个** —— 赭石色 sienna（浅色 `#A0522D`，深色 `#D9925B`）。禁止在交互元素上用多色渐变。要区分状态就用中性灰阶 + 这一个强调色的深浅。
- **设置页有自己的一层纸**：比主工作区更亮一点的米白底（浅色约 `#FBF7EE`）。
- **层次靠背景深度 + 1px 细线**，克制用阴影，有一套四级阴影（sm/md/lg/xl），取能读出来的最小那一级。
- **字体**：正文用衬线，UI 标签用无衬线，**数字用等宽** —— 这一条在这个界面里格外重要，一列要对齐的磅值和毫米数用比例字体会读错。
- **动效**：120–320ms，Apple 缓动。不要弹跳、不要大位移。
- **深浅双主题**：两套都要出，不是深色改个背景色了事。
- **选中 vs 悬停要分开**：选中用强调色淡染，悬停用中性灰。

## 4. 需要设计的四个界面

### 屏 1 ——「排版格式」设置页（最重要）

应用的设置是一个整窗页面：左侧固定 246px 的导航（通用 / 供应商与模型 / Prompt / 子代理 / 工作台 / **排版格式** ← 新增 / 同步与备份 / 用量 / 快捷键 / 关于），右侧是内容区。请按内容区 **1100–1440px 宽**来画。

这一页要装下：

- **预设列表**。内置的（手稿 / 素雅 / 公文 / 论文 / 投标）+ 作者自己建的 + 从 Word 文件读来的。
  - 其中**恰好一个是默认**。默认的含义很具体：AI 助手不特别指定格式时用的就是它。这个"默认"的选中态是这一页最重要的一个状态，要非常明确 —— 它不是"我现在正在看哪一个"，是"以后自动用哪一个"。**"当前选中查看"和"是默认"是两个正交的状态，都要能同时表达。**
  - 每一行要传达：名字、一句摘要（`仿宋_GB2312 三号 · 固定值28磅 · 首行缩进2字符`）、是不是默认、是内置还是自建（内置不可删）。
- **一个纸样预览**。不是渲染 Word，是一张**示意页**：按比例画出纸张、版心（页边距围出来的框）、标题层级、正文行、首行缩进的那一格。作者应该能不读数字就看出"这个版心很窄""这个标题是居中的"。
  - 请认真设计这个预览：它是唯一能让一屏数字变得可理解的东西。同时它**不能假装自己是所见即所得** —— 它是示意图，不是 Word。用什么手法把这件事说清楚（灰底、标注线、尺寸引线？）由你决定。
- **两个入口**：「新建预设」和「**从一份 Word 文件读取格式**」。后者是这个功能的杀手锏 —— 作者把甲方的模板丢进来，直接得到一套预设，不用人肉抄十二条要求。给它应有的分量，但不要喧宾夺主。

### 屏 2 —— 预设编辑抽屉

从右侧滑出的抽屉（这个应用里"列表 + 右侧抽屉"是既有模式，供应商与模型那一页就是这么做的）。要编辑的字段大约 30 个，分组如下：

| 组 | 字段 |
|---|---|
| 页面 | 纸张（A4 / Letter / B5 / 自定义）· 页边距 上右下左（mm）· 文档网格（每页行数 / 每行字数，可关） |
| 正文 | 中文字体 · 西文字体 · 字号（号数 + 磅联动）· 行距（三态 + 数值）· 首行缩进（字符数）· 段前 / 段后（磅）· 对齐 |
| 标题 1–4 | 每级：中文字体 · 字号 · 加粗 · 对齐 · 段前 / 段后 · 是否另起一页 |
| 其他块 | 引用 · 代码块 · 列表缩进 · 表格边框与表头 |
| 页眉页脚 | 页码位置与格式（三期，可以只画占位） |

设计上要解决的：

- **四级标题会占掉一大半篇幅**，而且四级长得几乎一样。找一个办法让它们既完整可编辑又不淹没正文那组（并排小卡？可折叠？一个层级选择器切换？—— 由你决定，但请说明理由）。
- **纸样预览应该跟着改**，实时。抽屉里放一个小的，还是让屏 1 的大预览联动，你定。
- **字号输入**：作者可能想输"三号"，也可能想输"16"。这两种输入怎么在一个控件里共存。
- **字体缺失提示**：不吓人，但要有。
- 抽屉要有**明确的保存 / 取消**，因为这是会长期生效的配置，不是即时预览。

### 屏 3 —— 「从一份 Word 文件读取格式」的确认

作者选了一个 .docx，应用读出它的排版参数。这一屏要回答两个问题：

1. **读出来的是什么** —— 一张规格表，和屏 1 的摘要同一套写法。
2. **接下来干什么** —— 「存为预设」（给个名字）/「这次就用它，不保存」/「设为默认」。

也要画**读失败**的样子：文件不是 .docx、或者它没有显式声明格式（全用 Word 默认值）。后一种不是错误，但要说清楚"这份文件本身没写死格式，读到的是 Word 的默认值"。

### 屏 4 —— 导出审批卡

AI 助手要写任何文件之前都会出一张卡，作者点批准才会真的写。这张卡出现在右侧 AI 抽屉的对话流里，**宽度约 560–620px**。已有的卡是同一套语言（标题行 + 一行右对齐的"分量"指标 + 正文 + 底部两个按钮：拒绝 / 批准）。

这张 Word 导出卡要装：

- **源 → 目标**：`周报.md → 周报.docx`
- **格式来源徽标** —— 这是这张卡区别于其他卡的地方，四种：
  - `默认格式`
  - `预设：公文`
  - `照 甲方模板.docx 模仿`
  - `预设：公文（改了 2 项）` ← 这一种要能标出**是哪两项**
- **规格摘要**：4–6 行最终值（字体字号 / 行距 / 首行缩进 / 纸张页边距）
- 底部：拒绝 / 批准

设计要点：作者会连续批准很多张卡，这张卡的**格式来源**必须在扫一眼时就跳出来 —— "用默认导的"和"照甲方模板导的"是两个完全不同的决定。

另外请画一张**批准之后的结果**：写到哪了、有没有降级（比如"文档里的数学公式退回成了原始文本"）。降级是要告诉作者的事实，不是错误，语气要中性。

### 屏 5 —— Beta 开关（只需确认，不用重新设计）

设置 → 通用 → 实验功能里加一行开关，和已有的「PPTX 导出（Beta）」「日中翻译（Beta）」同一个样式。**关闭时**：左侧导航里没有「排版格式」这一项，AI 助手也完全看不到导出 Word 这个能力。请在交付里说明关闭态下屏 1 的入口消失得是否自然。

## 5. 请把这些状态都画出来

- **一个预设都没有**（不可能真发生，内置的总在 —— 所以不用画）
- **作者还没建过任何自己的预设**：内置那几个之外空空的，要能让人明白"可以建"
- **预设被删除的确认**（内置不可删，删按钮应该是不出现还是禁用？）
- **默认预设被删了**（不允许？还是自动把默认让给别的？请给方案）
- **从 Word 读取失败** / **读到的是 Word 默认值**
- **字体本机未安装**（在列表摘要里、在编辑抽屉里、在审批卡上，三处的提示强度应该不同）
- **审批卡的四种格式来源**
- **导出结果：干净 / 有降级**
- **窄窗口**：设置页在 720px 以下导航会横过来变成一行，这一页在那个宽度下怎么排

## 7. 不要做的事

- 不要引入第二个强调色
- 不要加圆角
- 不要把它设计成"主题商店"——不要缩略图网格、不要"热门""推荐"、不要预览大图轮播。作者不是在挑好看的，是在核对合规。
- 不要把纸样预览做成看起来像所见即所得的 Word 编辑器 —— 它是示意图，越像真的越危险
- 不要把 30 个字段一次全铺在屏 1 上；也不要把它们藏到需要点四次才找得到
- 不要用比例字体排数字列
- 不要在审批卡上放"编辑格式"的入口（那会把一次导出变成一次配置会话，打断作者的节奏）—— 卡上只能"用"或"不用"
- 不要用红色表达"字体未安装"。那不是错误，文件仍然是对的
