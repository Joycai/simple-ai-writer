# 设计任务：在本项目里新建 `05h Word 排版格式（三）Word Format C.dc.html`

## 这两组是什么

`05e Word 排版格式（一）` 屏 1f 的编辑抽屉里，「页眉页脚」还是一张写着「三期做」的占位卡。三期已经做了，而且比占位卡上列的多一组：

1. **页眉页脚**——页眉文字（可对齐）、页码写法（`1` / `— 1 —` / `1 / 12`，可对齐）、页眉横线，以及三个只在前面设了东西时才有意义的开关：奇偶页不同、首页不同、每章页码重来。它的第一条规矩不是任何一个字段，而是**留空就一行都不发**：没设过的文稿里不会出现一个空页眉占着位置，作者不会打开 Word 问「我什么时候设过页眉」。
2. **标题自动编号**——一个总开关 + H1–H4 每级一种写法（一、 / （一） / 1. / （1） / 1.1.1 含上级 / 不编号）。由 Word 自己编号（真正的多级列表，不是打进标题里的死字），所以正文标题里**不要**再手写「一、」。

其余背景直接看 `05e`（1a 列表与摘要写法、1c 纸样的四种画法、1f 抽屉、1g「四级标题怎么排」的方案与理由）和 `05f`（1h/1i 读取模态的规格表与来源列、1j 审批卡、1l 删除确认的深中性键）。不用重新解释产品和视觉规范。

## 这次要解决的张力

### A · 标题编号（抽屉内）

**A1. 它是「标题 1–4」表的第七列，还是自己一组？** 1g 定下的原则是：四级的值要能**横向比**，甲方要求是逐列念的（「一级标题黑体二号居中」）。而甲方要求里紧接着的一句常常就是「一级标题用『一、』，二级用『（一）』」——编号写法正是这张表该有的一列。今天它是抽屉末尾单独一组、四行下拉。请二选一并说明理由：并进 1f 那张 H1–H4 表（多一列「编号」，点行展开后多一个字段），还是留成一组但让四级样例像表一样对齐。

**A2. 写法名认不出来，样子一眼就认得。** 六种写法今天下拉里写的是「一、二、三、」「（一）（二）」这种带样例的名字，右侧再回显一次当前级的样例（含上级的那种回显 `1.1.1`）。请决定样例和名字要不要合成一个（下拉项就是样例），以及「不编号」在四级并排的摘要里用 `—` 占位——这个 `—` 和 `05c 模型编辑` 里「未设＝虚线边」是不是同一个记号，要不要统一。

**A3. 「正文里不要手写序号」这句话的分量。** 开关一开，作者稿子里已经打好的「一、总体要求」会排成「一、一、总体要求」。今天这只是开关旁一行 10.5px 的等宽回显。它不是错误提示（码里没有检测、也不剥离），但它是这一组唯一会让作者吃亏的地方。请给它一个比回显重、比警告轻的位置。

### B · 页眉页脚（抽屉内）

**B1. 依赖字段是「出现」还是「虚线」。** 奇偶页不同 / 每章页码重来 只在设了页码时出现，首页不同只在三者任一设了时出现——所以这一组会从三行长到六行。`05c` 的方言是**未设＝虚线边，不是不见**。请决定这三行在没有前提时是不画、还是虚线禁用并挂一句「先设页码」。判断依据：作者会不会在没设页码时找「首页不同」。

**B2. 「留空就一行都不发」住在哪。** 今天有三处在说它：页眉文字框的占位「留空＝不写页眉」、页码下拉的第一项「不写页码」、组末那块琥珀左边的提示框。1f 占位卡上那句「不写任何默认内容，免得作者以为设过」搬进了这块提示框。三处是不是多了；那块提示框是留、是并进分组标题的摘要、还是删。

**B3. 纸样要不要画页码。** 1c 的四种画法里，页边距是斜纹、「不可放正文的地方」——而页码恰恰是唯一一样**放在斜纹里**的东西。请决定纸样（1f 抽屉里那张小的，和屏 1 那张大的，同一套画法）要不要在页脚位置画一个等宽的 `— 1 —` / `1` / `1 / 12`，按对齐落在左 / 中 / 右，以及页眉横线要不要画成版心上方的一根 1px 线。约束照 1c：**不翻页、不画第二张纸**——奇偶页不同和首页不同留给文字，纸样只画「默认那一页」。

**B4. 奇偶页不同是一条规则，不是两套字段。** 偶数页的左右对齐互换、居中不动——作者只设一次「靠右」。今天靠回显那句话说明。页码对齐段（左 / 中 / 右）在「奇偶页不同」开着时，要不要在段上就说出「奇 右 · 偶 左」，而不是让作者读一句话。

**B5. 「每章页码重来」会让开 H1 的「另起一页」。** 分节符自己分页，两个叠起来每章前面多一张白纸，所以码让标题那一个让开。这是**两组之间**的联动：1f 标题表里 H1 那一行「另页 是」在这个开关开着时事实上不生效。请决定标题表那一格要不要有个说法（比如写「分节」代替「是」），还是只在这个开关的回显里说。

### C · 抽屉之外：这两组还有三处看不见

**C1. 列表行摘要与审批卡。** 1a 的一行摘要和 1j 的 4–6 行规格摘要都不提页码与编号。审批卡的原则是「格式来源是唯一的新东西」、规格 4–6 行；甲方要求里「页码居中、— 1 —」和「一级标题 一、」又确实是核对项。请决定：① 永远不进摘要；② 只在**不是「不写 / 关」**时追加一行 `页码 — 1 — 右 · 编号 一、（一）1.（1）`；③ 进摘要但进的是列表行的第二行而不是审批卡。三处摘要同一串写法（1g 立的规矩），所以这个决定一次管三处。

**C2. 读取模态的诚实。** 1h 的规格表按「这份文件自己写死的 / Word 出厂值补的 / 没出现」三种来源分行。页眉页脚和编号**这一版不读**——它们不是「没出现」，是没去看。一套「读自 甲方模板.docx」的预设因此页码永远是「不写」，作者却以为模仿覆盖了全部。请给这两组在 1h 里一个样子：一行灰字「页眉页脚 / 标题编号 · 这一版不从文件里读，存为预设后到抽屉里设」，还是干脆不出现。判断依据只有一条：作者点「存为预设」之前必须知道这两组是空的。

**C3. 助手说不动它们。** 模型能改的六项（字体 / 字号 / 行距 / 缩进 / 页边距）不含页码与编号——「这次页码用 — 1 —」只能靠换预设。1j 的「预设：公文（改了 2 项）」因此永远不会写出这两组的改动。这条不用画，写进 1z 即可：卡上不该出现「改了页码」这种它做不到的话。

## 交付什么

一个 `.dc.html`，屏号 1a 起，浅 / 深两套，带设计说明侧栏：

- **1a** 编辑抽屉的尾部 · 公文预设：标题编号开（一、 （一） 1. （1））+ 页眉页脚（`— 1 —` 靠右 · 奇偶页不同 · 首页不同），右栏纸样若按 B3 画了页码就一起画。
- **1b** 同一位置 · 素雅预设：编号关、页眉页脚什么都没设——B1 的依赖行怎么处理、B2 那块提示框留不留，都在这一屏定。
- **1c** 纸样 · 细节放大（接 05e 屏 1c 的编号方式）：页码在页脚斜纹里的三种对齐、页眉横线、标题条上的编号记号（若有）。若 B3 决定不画，这一屏改成一段说明为什么不画。
- **1d** 标题 1–4 表 · A1 的两个方案并排（第七列 vs 独立一组），选一个并写理由。

## 数据边界（设计只能用这些字段）

页眉页脚（`HeaderFooter`）：
```
headerText            页眉文字，空串＝不写页眉
headerAlign           left | center | right（只在有文字时有意义）
pageNumber            none | plain（1）| dashed（— 1 —）| ofTotal（1 / 12）

headerRule            页眉横线，可以没有文字单独存在
differentOddEven      偶数页左右互换、居中不动——一条规则，不是第二套对齐
differentFirstPage    第一页什么都不写（不是「首页写别的」）
restartEachChapter    每个 H1 另起一节、页码从 1 起；H1 的 pageBreakBefore 让开
```
标题编号（`HeadingNumbering`）：
```

levels[4]             每级 none | chinese（一、）| chineseParen（（一））| decimal（1.）
```

## 沿用 `05e` / `05f` 的方言，以及这一轮容易踩的几条

- 分组标题旁一行**等宽**摘要，和列表行、审批卡同一串写法（1g）；数字、样例（`— 1 —` `1 / 12` `一、` `1.1.1`）一律 mono。
- 纸样的四种画法（斜纹 / 虚线框 / 灰条 / 引线与刻度）不加第五种；**不翻页、不画第二张纸、不承诺是 Word**（1c「刻意没有的东西」）。
- 未设＝虚线边（`05c`），不是消失也不是「设为 0」；开关是方形的；全局零圆角；唯一强调色赭石，选中用赭石 tint，悬停用中性底。
- **不用红**：A3「不要手写序号」和 C2「这一版不读」都是提醒，不是错误——语气照 05f 屏 1k 的降级写法（中性灰、方形小标记、陈述句）。
- 文案照今天的 i18n 键（本文上半部分表格里引了原句），术语是「页眉 / 页脚 / 页码 / 标题编号 / 预设」，不要新造。
- 不做：首页另一套内容、页脚文字、页码起始值、章号前缀、编号分隔符、第二张纸样、「剥离手写序号」的开关、审批卡上编辑格式的入口（05e §7 的旧规矩仍然有效）。
